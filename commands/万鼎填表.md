# /万鼎填表

用户给一个 Excel 绝对路径（`file_path`），目标是把该 Excel 的产品描述列自动填入匹配到的价格。

## 步骤

1. **PreToolUse hook 会校验 `file_path` 在白名单路径下**（在 plugin userConfig.approved_paths 里设）
2. 调 `mcp__quotation__parse_excel_smart` 解析输入
   - 拿到 product description 列的 row list
3. 调 `mcp__quotation__fill_quotation_sheet`
   - 拿到结果：`{ matched: [...], ambiguous: [...], unmatched: [...] }`
4. **对 `ambiguous` 逐行处理**：
   - 读 `selection_context.wanding_business_knowledge` + 候选 → 选 1 个
   - 选不出来 → 用 `mcp__quotation__ask_clarification` 问用户一句
5. **汇总报告**给用户：matched / ambiguous-resolved / ambiguous-pending / unmatched 各多少

## 输出路径

- `output_path` 缺省时，写到 `<file_path>.filled.<timestamp>.xlsx`
- 不要覆盖原 Excel（PreToolUse hook 会拦）

## 错误处理

- `file_path` 不存在 → 直接报路径错
- 解析后没有 product description 列 → 让用户确认列名
- 全部 ambiguous → 不写文件，让用户先答澄清问题
