# /万鼎库存

用户给一组 product code（如 8010071381、6010010203），查每个 code 的可用库存。

## 工具调用

- 调 `mcp__quotation__get_inventory_by_code_batch`，参数：
  - `codes`: 用户给的 code 列表
  - `max 50 items per call`（超出请分批）

## 输出

每个 code 一行：

```
8010071381 → 可用 666 PCS（仓库 1165 PCS）
6010010203 → 无可用库存
9999999999 → [not found] 该 code 不存在
```

## 错误处理

- 单个 code 失败不影响其他 code
- 如果用户给的不是 code 格式（不是 7-10 位数字）→ 提醒"应该是 product code"
- 如果全部失败 → 让用户检查 Accurate API 凭据是否配置（plugin userConfig.aol_token）
